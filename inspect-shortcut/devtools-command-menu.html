The DevTools Command Menu, drawn out

One shortcut opens a search box for almost every hidden DevTools feature. Press it, type a few letters, hit Enter.

Prefixes worth knowing

  1. Open the Command Menu, then delete the > and type a file name to jump to any source file.
  2. @ jumps to a function in the open file, : to a line number, ? lists every prefix.
  3. ! runs a saved snippet. Press Esc at any time to toggle the console drawer.

Handy extras

  1. Hard reload with Ctrl+Shift+R (Cmd+Shift+R on Mac). A plain Ctrl+R may reuse cached files.
  2. Network panel: tick Preserve log to keep requests across redirects, and right-click a request for Copy as fetch or Copy as cURL.
  3. Performance panel: use the CPU throttling setting to see how a slower phone copes.
  4. Rendering drawer: turn on Paint flashing and Layout Shift Regions to spot costly repaints.
Menu labels shift a little between Chrome versions. If a command is missing, type a keyword from its name.
